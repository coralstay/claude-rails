# TASK-15: 톤 윤문

## 문제

사용자 피드백: "조금 문서가 공격적인데 윤문으로 써줘. 지금 글은 잘쓰여졌어." — 내용/구조는
괜찮지만 표현이 날카롭다는 지적.

## 무엇을 고쳤나

README.md와 doc-2 1장에서 Claude를 탓하는 듯한 두 표현을 찾아 고쳤다:

- "Claude 자신의 판단 오류" → "의도와 다르게 흘러갈 수 있는 지점들이 있어서다"
- "Claude가 어겨도(고의든 실수든)" → "규칙을 벗어나는 순간"

## 왜 이 방법을 택했나

"판단 오류"와 "고의든 실수든"은 Claude에게 잘못/의도를 귀속시키는 어휘다. 실제로
전달하려는 내용(프롬프트 인젝션, 컨텍스트 압축 같은 시스템적 요인 때문에 자연어 약속이
안 지켜진다는 것)은 Claude를 탓하는 내용이 아니었으므로, 어휘만 중립적으로 바꾸고
내용/문단 순서/구조는 전혀 건드리지 않았다 — 사용자가 "지금 글은 잘 쓰였다"고 했으므로
구조를 다시 설계할 이유가 없었다.
