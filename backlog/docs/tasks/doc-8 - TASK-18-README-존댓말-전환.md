# TASK-18: README 존댓말 전환

## 문제

README.md가 반말체(~이다/~한다/~했다)로 쓰여 있었다. 사용자가 "리드미 말투 다 존댓말로
바꿔!!!!"라고 명확히 요청했다.

## 무엇을 했나

README.md의 모든 프로즈 문장 종결어미를 존댓말(~입니다/~합니다/~했습니다)로 바꿨다.
표 셀 안의 설명(예: "워크플로 가이드/무결성 이슈 주입")은 동사 종결어미가 없는 명사구라
말투 구분이 적용되지 않으므로 그대로 뒀다. 내용/구조/문단 순서는 전혀 안 건드렸다.

작업 중 부수적으로 발견한 것: PR #11이 merge될 때 `main` 브랜치를 내 작업 브랜치에
병합하는 과정에서, PR #10에서 추가됐던 옛 "훅 목록" 평면 표(이름+설명, 28행)가 TASK-17의
새 생애주기 표(41행)와 함께 남아 중복돼 있었다. AC에는 없었지만 같은 파일에 남은 명백한
merge 잔재라 이번에 같이 제거했다.

## 왜 이 방법을 택했나

말투 전환은 순수하게 기계적인 작업이라 판단이 필요한 지점이 거의 없었다 — 문장 종결어미만
바꾸고 나머지는 전혀 건드리지 않는 게 원칙. 유일한 판단은 "표 셀도 존댓말로 바꿀 것인가"
였는데, 명사구는 애초에 반말/존댓말 구분이 없는 형태라 대상에서 제외했다.
