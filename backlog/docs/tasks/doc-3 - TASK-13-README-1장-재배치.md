# TASK-13: README 1장 재배치

## 문제

README 1장("왜 이게 있는가")이 "기계적 강제 vs 사람 판단" 경계선을 먼저 설명하고, 그 다음에야
사용자 의도("Claude가 내가 의도한 대로 행동하게")를 언급했다. "무엇을 하는가(메커니즘)"가
"왜 하는가(의도)"보다 먼저 나오는 순서였다 — 사용자가 이 프로젝트를 다시 봤을 때 "의도가
드러나지 않는다"고 느낀 원인.

## 해결

최상단 태그라인과 1장 첫 문단을 사용자 의도 문장("Claude Code와 함께 작업할 때, Claude가
내가 의도한 대로 행동하게 만드는 것")으로 교체하고, 기존 "기계적 강제 vs 사람 판단" 설명은
"그 의도를 실제로 어떻게 구현했는가"를 설명하는 두 번째 문단으로 재배치했다. 내용은 하나도
안 버리고 순서만 뒤집었다.

## 왜 이 방법을 택했나

기존 설명(기계적 강제/사람 판단 구분)은 이 세션에서 힘들게 검증한 정확한 서술이라 버릴
이유가 없었다 — 문제는 순서였다. "의도(왜) → 구현(어떻게)" 순서가 "구현(어떻게) → 의도(왜)"
순서보다 처음 읽는 사람에게 더 잘 읽힌다는 게 이 태스크의 판단.
