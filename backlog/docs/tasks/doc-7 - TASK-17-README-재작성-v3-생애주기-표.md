# TASK-17: README 재작성 v3 (생애주기 표)

## 문제

사용자가 README에 더 담아야 할 내용을 구체적으로 지시했다: (1) 왜 필요했는지/무엇을
만들었는지를 더 분명히, (2) "에이전트를 사용하기 위한 개인용 훅 모음집"이라는 소개
문구, (3) Python을 선택한 이유(가독성, 작성자의 Python 생태계 친숙도 — 원래 여러
개는 bash였다), (4) 훅들을 Claude Code 훅 생애주기(11개 이벤트) 기준으로 어떤 훅이
어느 단계에 도는지 표로.

## 무엇을 했나

README를 다시 확장했다(65→95줄): "왜 필요했나"/"무엇을 만들었나"를 별도 섹션으로
분리, "주요 특징"에 Python 선택 이유 추가, 기존 "훅 목록"(이름+설명, 28행) 표를
Claude Code 생애주기별 표(41행 — 여러 이벤트에 걸린 훅은 행을 반복)로 교체했다.

## 왜 이 방법을 택했나

TASK-14에서 "짧게" 줄였다가 TASK-16에서 표를 다시 넣고 이번에 더 확장됐다 —
모순처럼 보이지만, 매번 그 시점의 사용자 요청을 따른 것이다(decision-6 참고). 생애주기
표는 실제 `settings.hooks.json` 등록(이벤트/matcher/if)을 python3로 직접 파싱해서
행 수(41)와 내용을 대조 검증한 뒤 작성했다 — 추측으로 표를 채우지 않았다.
