# claude-rails

Claude Code와 함께 작업할 때, Claude가 내가 의도한 대로 행동하도록 만들기 위해 만든 훅
모음이다.

## 왜

CLAUDE.md에 "이렇게 해줘"라고 적어두는 것만으로는 매번 지켜지지 않는다 — 프롬프트
인젝션, 컨텍스트 압축, Claude 자신의 판단 오류 때문에. 그래서 기계적으로 검증 가능한
규칙은 훅(코드)으로 물리적으로 강제하고, 결국 사람 판단이 필요한 두 지점(백로그 승인,
push 전 코드 리뷰)만 정직하게 사람에게 남긴다. Claude가 어겨도(고의든 실수든) 액션
자체가 실행되지 않는 게 핵심이다.

## 뭐가 있나

28개 훅 — backlog.md 워크플로 전용 5개 + 프로젝트 종류와 무관하게 항상 켜져 있는 범용
안전/관측 23개(시크릿 보호, 위험 명령 차단, 설정 변조 감시, 복붙 코드 drift 감시 등).
전부 개인 fork 안에서만 강하게 적용되고, 운영 레포로의 PR은 항상 사람이 직접 연다.

## 설치

```bash
cd ~/githubs/claude-rails && ./install.sh
```

## 더 알고 싶으면

- **전체 스펙**(Phase 명세, HIL 표, 훅 28개 하나하나, 설치/삭제, 파일 구성) →
  `backlog doc view doc-2`
- **삽질/실수 기록** → [`삽질기록.md`](./삽질기록.md)
- **세션 회고** → `backlog doc list`
- **핵심 의사결정** → `backlog decision list`
- **알려진 한계 / 다음 단계 후보** → `backlog draft list`
